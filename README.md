# Swahili News Classification

Group project for Formative 2: classifying Swahili news articles into six topics with sequential models.

## Branches

Each goal has its own branch. Work is merged into `main` through pull requests.

| Branch | Goal | Owner |
|---|---|---|
| `data-pipeline-eda` | Data loading, cleaning, exploratory analysis | Gentil Tonny Christian Iradukunda |
| `baseline-models` | TF-IDF Naive Bayes and Logistic Regression, evaluation metrics | Dan Paul Dushime |
| `bilstm-model` | BiLSTM with attention | Rene Pierre Ntabana |
| `textcnn-model` | TextCNN | Thierry Alain Tresor Ibyishaka |
| `afriberta-model` | AfriBERTa-small fine-tuning | Gentil Tonny Christian Iradukunda |
| `model-comparison` | Comparison tables and significance tests | Dan Paul Dushime |
| `error-analysis` | Error analysis | Thierry Alain Tresor Ibyishaka |
| `colab-notebook` | End-to-end Colab notebook | Rene Pierre Ntabana |
| `report` | Research report | Gentil Tonny Christian Iradukunda |
